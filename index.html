My First Repository

GitとGitHubを学ぶためのはじめてのリポジトリ

このプロジェクトについて

このリポジトリは、GitとGitHubの基本的な使い方を学ぶために作成されました。バージョン管理の基礎から、コミット・ブランチ・プルリクエストまでを実践的に体験できます。

学べること

  • Gitの基本コマンドの使い方
  • GitHubでのコード管理
  • ブランチを使った開発ワークフロー
  • プルリクエストによるコードレビュー

クイックスタート

git clone https://github.com/u1-shige/my-first-repository.git
cd my-first-repository
git status
