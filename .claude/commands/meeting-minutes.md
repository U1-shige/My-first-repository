Whisper Notes（iPhoneアプリ）で文字起こしされたテキストから、構造化された議事録を生成してください。

## 引数

`$ARGUMENTS` の内容に応じて動作を切り替えます：

- **引数なし** → テキスト対話モード（会議情報をユーザーに質問して議事録を作成）
- **Box ファイルID**（英数字のみの文字列、例: `abc123def456`）→ Box から文字起こしテキストを取得
- **ローカルファイルパス**（`/` または `./` で始まる文字列）→ ローカルファイルを読み込む

## 手順

### 引数なしの場合（テキスト対話モード）

ユーザーに以下を質問し、回答をもとに議事録を作成してください：
1. 会議名・テーマ
2. 開催日時（日付・開始〜終了時刻）
3. 参加者
4. 議題
5. 各議題の決定事項・保留事項
6. アクションアイテム（担当者・期限）

### Box ファイルIDの場合

1. Box MCP ツール（`mcp__8004ad3b-98e4-41c0-9b57-a954a42597dc__get_file_content`）を使ってファイルIDのテキストを取得する
2. 取得した文字起こしテキストを解析して議事録を生成する（下記「文字起こしからの解析」を参照）

### ローカルファイルパスの場合

1. `Read` ツールでファイルを読み込む
2. 取得した文字起こしテキストを解析して議事録を生成する（下記「文字起こしからの解析」を参照）

## 文字起こしからの解析

Whisper Notes が出力した文字起こしテキストを以下の方針で解析してください：

| 項目 | 抽出方針 |
|------|---------|
| 会議名 | 冒頭の発言や話題の文脈から推定。不明なら `（要確認）` |
| 日時 | ファイル名や本文中の日時表現から抽出。不明なら今日の日付を使用 |
| 参加者 | 「〜さん」「〜です」等の発言者名から収集 |
| 議題 | 話題の転換点（「次に」「続いて」「では」等）で区切って分類 |
| 決定事項 | 「〜することになりました」「〜で決定」「〜でいきましょう」等の表現を抽出 |
| 保留事項 | 「〜は持ち越し」「〜は次回」「要検討」等の表現を抽出 |
| アクションアイテム | 「〜をお願いします」「〜担当」「〜までに」等の表現から担当者・期限とセットで抽出 |

不明な項目は `（要確認）` と記載してください。推測で記入した場合は末尾に `※` を付けてください。

## 議事録テンプレート

以下のフォーマットで議事録を生成してください：

```markdown
# 議事録

## 基本情報

| 項目 | 内容 |
|------|------|
| 会議名 | （会議名） |
| 開催日時 | （日付） （開始時刻）〜（終了時刻） |
| 開催場所 | （場所またはオンライン会議ツール名） |
| 参加者 | （参加者一覧） |
| 記録者 | Whisper Notes（自動文字起こし） |
| 次回開催予定 | （次回日時、未定なら「未定」） |

---

## 議題

1. （議題1）
2. （議題2）

---

## 議事内容

### 1. （議題1）

**概要**
（議論の概要）

**決定事項**
- （決定事項）

**保留事項**
- （保留事項があれば）

---

## アクションアイテム

| # | タスク | 担当者 | 期限 | ステータス |
|---|--------|--------|------|------------|
| 1 | （タスク内容） | （担当者） | （期限） | 未着手 |

---

## 次回議題（案）

- （次回持ち越し議題）

---

## 備考

（特記事項）
```

## ファイル保存

- ファイル名: `minutes_YYYYMMDD.md`（日付は会議開催日）
- 同名ファイルが存在する場合: `minutes_YYYYMMDD_会議名.md`
- 保存場所: 文字起こしファイルと同じディレクトリ（ローカルファイルの場合）、またはカレントディレクトリ
- 保存後、ファイルの絶対パスをユーザーに伝えてください
