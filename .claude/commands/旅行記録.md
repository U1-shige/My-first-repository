# 旅行記録スキル

旅行の記録を作成・閲覧するスキルです。

## 引数について

- 引数なし or `一覧` → 過去の旅行記録を一覧表示する
- `新規` → 新しい旅行記録を対話形式で作成する
- `YYYY-MM-DD YYYY-MM-DD` → **Google タイムライン自動記録モード**（例: `2025-08-10 2025-08-15`）
- `<旅行名>` → 指定した旅行の詳細を表示する

実行時の引数: $ARGUMENTS

---

### 📱 スマートフォンから使う場合

1. スマホで [takeout.google.com](https://takeout.google.com) にアクセスし、「場所の履歴」の JSON をダウンロード
2. Claude Code の Web 画面でファイルをアップロード（入力欄横のペーパークリップアイコン）
3. アップロードされたファイルのパスをメモする
4. `/旅行記録 YYYY-MM-DD YYYY-MM-DD` を実行して、聞かれたときにパスを貼り付け

---

## 動作手順

### 一覧表示モード（引数なし or `一覧`）

1. `travel-logs/` ディレクトリ内の全 `.md` ファイルを読み込む
2. 各ファイルのフロントマター（`destination`, `start_date`, `end_date`, `rating`）を抽出する
3. 以下の表形式で出力する：

```
| # | 旅行先 | 期間 | 評価 |
|---|--------|------|------|
| 1 | 京都   | 2025-03-20 〜 03-22 | ★★★★☆ |
```

4. 記録がない場合は「まだ旅行記録がありません。`/旅行記録 新規` で最初の記録を作りましょう！」と表示する。

---

### 新規作成モード（引数が `新規`）

以下の質問を **1問ずつ** ユーザーに尋ねる（AskUserQuestion ではなく、チャット形式で順番に聞いていく）。

1. **旅行先（国・都市）** ── 例: 「京都・奈良」「タイ・バンコク」
2. **旅行期間** ── 出発日と帰着日（例: 2025-08-10 〜 2025-08-15）
3. **旅行の目的・テーマ** ── 観光 / グルメ / ビジネス / 温泉 など
4. **印象に残った場所・体験** ── 自由記述
5. **おすすめスポット** ── また行きたい・友人に勧めたい場所
6. **費用の目安** ── 交通費・宿泊費・食費など概算（任意）
7. **総合評価** ── ★1〜5
8. **ひとことメモ** ── 次回へのメモや感想

全項目が揃ったら、以下のマークダウン形式でファイルを作成する。

**ファイル名**: `travel-logs/YYYYMMDD_<旅行先をスネークケースに>.md`
（例: `travel-logs/20250810_bangkok.md`）

**ファイル内容テンプレート**:

```markdown
---
destination: <旅行先>
start_date: <出発日 YYYY-MM-DD>
end_date: <帰着日 YYYY-MM-DD>
theme: <テーマ>
rating: <★の数 1-5>
created_at: <今日の日付 YYYY-MM-DD>
---

# <旅行先> の旅 🗺️

**期間**: <出発日> 〜 <帰着日>  
**テーマ**: <テーマ>  
**評価**: <★★★★☆ のような表記>

---

## ✨ 印象に残った場所・体験

<印象に残った場所・体験>

---

## 📍 おすすめスポット

<おすすめスポット>

---

## 💰 費用メモ

<費用の目安（記入があれば）>

---

## 📝 次回へのメモ

<ひとことメモ>
```

ファイル作成後、「✅ `<ファイル名>` に記録しました！」と伝え、記録内容のサマリーを表示する。

---

### 詳細表示モード（旅行名を引数に指定）

1. `travel-logs/` 内のファイルを検索し、`destination` が引数に部分一致するものを探す
2. 見つかったファイルの内容をそのまま表示する
3. 見つからない場合は「該当する記録が見つかりませんでした」と表示し、一覧を表示する

---

## 注意事項

- ファイルの読み書きには Read / Write / Edit ツールを使う
- 旅行先名に日本語が含まれる場合、ファイル名はローマ字またはピンインに変換する
- 記録は必ず `travel-logs/` ディレクトリに保存する

---

### タイムライン記録モード（引数が `YYYY-MM-DD YYYY-MM-DD` 形式のとき）

引数が `2025-08-10 2025-08-15` のように**スペース区切りの日付 2 つ**であれば、このモードで動作する。

#### STEP 1: 入力収集

以下を**チャット形式で 1 問ずつ**順番に確認する（AskUserQuestion ではなく対話形式）：

1. **旅行名** ── 例: 「8月タイ旅行」
2. **Google Takeout JSON ファイルパス** ── 複数月分ある場合はスペース区切りで複数指定可
   - スマホでアップロードした場合はそのパスを貼り付けてもらう
3. **Notion 親ページ ID**（任意。「スキップ」と答えた場合は Notion への保存を行わない）

#### STEP 2: Timeline JSON のパース

以下の Python スクリプトを `/tmp/parse_timeline.py` に書き出し、`python3` で実行する。
`python3` がなければ `python` を試す。どちらもなければ処理を中断してユーザーに案内する。

```python
#!/usr/bin/env python3
import json, sys
from datetime import datetime, date

def parse_timeline(json_paths, start_str, end_str):
    start_date = date.fromisoformat(start_str)
    end_date   = date.fromisoformat(end_str)
    results = []
    for json_path in json_paths:
        with open(json_path, encoding="utf-8") as f:
            data = json.load(f)
        for obj in data.get("timelineObjects", []):
            pv = obj.get("placeVisit")
            if not pv:
                continue
            try:
                start_dt = datetime.fromisoformat(
                    pv["duration"]["startTimestamp"].replace("Z", "+00:00"))
                end_dt   = datetime.fromisoformat(
                    pv["duration"]["endTimestamp"].replace("Z", "+00:00"))
            except Exception:
                continue
            if end_dt.date() < start_date or start_dt.date() > end_date:
                continue
            name    = pv["location"].get("name", "不明")
            address = pv["location"].get("address", "")
            # 宿泊判定: 滞在時間 > 6h かつ深夜(22時〜翌6時)を含む（UTC基準）
            duration_h    = (end_dt - start_dt).total_seconds() / 3600
            local_start_h = start_dt.hour
            is_hotel = duration_h >= 6 and (local_start_h >= 22 or local_start_h <= 6)
            results.append({
                "name": name, "address": address,
                "start": start_dt.strftime("%Y-%m-%d %H:%M"),
                "end":   end_dt.strftime("%Y-%m-%d %H:%M"),
                "is_hotel": is_hotel
            })
    results.sort(key=lambda x: x["start"])
    print(json.dumps(results, ensure_ascii=False, indent=2))

if __name__ == "__main__":
    # 引数: start_date end_date json_path1 [json_path2 ...]
    parse_timeline(sys.argv[3:], sys.argv[1], sys.argv[2])
```

実行例:
```bash
python3 /tmp/parse_timeline.py 2025-08-10 2025-08-15 /path/to/timeline.json
```

出力: JSON 形式の施設リスト（ホテルフラグ付き、時系列順）

結果が空配列 `[]` の場合は「指定期間内に訪問施設が見つかりませんでした」と伝えて終了する。

#### STEP 3: ローカル Markdown 生成

保存先: `travel-logs/YYYYMMDD_<旅行名>/旅行記録.md`

- ディレクトリが存在しない場合は Bash で `mkdir -p` して作成する
- 旅行名に日本語が含まれる場合はそのまま使用してよい（ファイルシステムが許容）
- ホテルと施設を時系列で並べ、各エントリーに「📸 写真: （Notion に手動で追加してください）」を記載する

**テンプレート**:
```markdown
---
destination: <旅行名>
start_date: <開始日 YYYY-MM-DD>
end_date: <終了日 YYYY-MM-DD>
created_at: <今日の日付 YYYY-MM-DD>
---

# <旅行名> 🗺️

**期間**: <開始日> 〜 <終了日>
**訪問施設**: <施設数>か所（うちホテル <ホテル数>泊）

---

## 🏨 <ホテル名>（泊）
- チェックイン: <start>
- チェックアウト: <end>
- 住所: <address>
- 📸 写真: （Notion に手動で追加してください）

## 📍 <施設名>
- 滞在: <start> 〜 <end>
- 住所: <address>
- 📸 写真: （Notion に手動で追加してください）
```

#### STEP 4: Notion ページ作成（親ページ ID が指定された場合のみ）

`notion-create-pages` ツールを使用して以下の構成でページを作成する。

**ページタイトル**: `<旅行名> (<開始日>〜<終了日>)`

**ブロック構成**:
- heading_1: 「旅行概要」
  - paragraph: 「期間: <開始日> 〜 <終了日>」
  - paragraph: 「訪問施設: <施設数>か所（うちホテル <ホテル数>泊）」
- ホテルごとに:
  - heading_2: 「🏨 <ホテル名>」
  - paragraph: 「チェックイン: <start> / チェックアウト: <end>」
  - paragraph: 「住所: <address>」
  - paragraph: 「📸 写真: ここに写真を追加してください（手動）」
- 日帰り施設ごとに:
  - heading_2: 「📍 <施設名>」
  - paragraph: 「滞在: <start> 〜 <end>」
  - paragraph: 「住所: <address>」
  - paragraph: 「📸 写真: ここに写真を追加してください（手動）」

Notion への保存が成功したら、作成されたページの URL を表示する。
Notion 接続に失敗した場合は「Notion への保存はスキップしました。ローカルの Markdown は保存済みです。」と伝える。

#### 完了メッセージ

処理完了後、以下を表示する：
```
✅ 旅行記録を作成しました！

📁 ローカル: travel-logs/YYYYMMDD_<旅行名>/旅行記録.md
  - ホテル: X泊
  - 訪問施設: X か所

📓 Notion: <作成されたページURL（またはスキップ済み）>

📸 写真は各施設の Notion ブロックに手動で追加してください。
```
