# My First Repository

はじめてのGitHubリポジトリへようこそ！

## 概要

このリポジトリは、GitとGitHubの基本的な使い方を学ぶために作成されました。
バージョン管理の基礎から、コミット、ブランチ、プルリクエストまでを実践的に学べます。

## 目的

- Gitの基本コマンドを習得する
- GitHubを使ったコードの管理方法を理解する
- ブランチを使った開発ワークフローを学ぶ
- プルリクエストによるコードレビューの流れを体験する

## はじめ方

### リポジトリをクローンする

```bash
git clone https://github.com/u1-shige/my-first-repository.git
cd my-first-repository
```

### 基本的なGitコマンド

```bash
# 変更を確認する
git status

# ファイルをステージングする
git add .

# コミットする
git commit -m "コミットメッセージ"

# リモートにプッシュする
git push origin main
```
